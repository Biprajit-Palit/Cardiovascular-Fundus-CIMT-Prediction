# B.Tech Thesis Draft

This folder contains the editable LaTeX thesis for the project **Early Cardiovascular Disease Prediction Through High-Resolution Fundus Images for Ophthalmics**.

## Main files

- `Final_Thesis.tex` is the main document and contains the NIT Agartala front matter.
- `chapter1.tex` through `chapter6.tex` contain the thesis chapters.
- `bib/mybib.bib` contains bibliography entries.
- `images/experiment_results/` contains copies of the saved training and exploratory fusion plots used in the report.
- `nitathesis.cls` and the included `.sty` files provide the supplied thesis format.

Compile `Final_Thesis.tex` with a LaTeX environment that includes BibTeX support. Run the compiler enough times to resolve cross-references and bibliography citations.
